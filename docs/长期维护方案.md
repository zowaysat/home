# 长期维护与二开方案

> 项目：無名の主页（`imsyy/home` v4.1.4，当前仓库 `zowaysat/home` fork）
> 文档版本：1.0 ｜ 编写日期：2026-11-05 ｜ 适用分支：`dev`
> 关联文档：[升级检查清单](./升级检查清单.md)

---

## 0. 摘要

**保留 UI 与交互资产，重做工程底座；先让项目"永远能构建、外部接口挂了也能用"，再建测试和 CI，最后升级依赖与扩展能力；与已存档的上游脱钩，自己当主干。**

这不是一次重写，而是一条 7–10 人日、分 3 个阶段的渐进路线。每一步都可以独立上线、独立回滚。

---

## 1. 目标与边界

### 1.1 五个目标

| 目标 | 含义 | 验收方式 |
|---|---|---|
| 可构建 | 任何一台干净机器 `pnpm install && pnpm build` 一次成功，不依赖手工建 `.env` | 在 CI 上验证，不依赖本机缓存 |
| 可配置 | 站点信息、外部服务、功能开关收敛到一处，改配置不改代码 | 改 `.env` / `content/*.json` 即可换数据源、换文案 |
| 可降级 | 任一第三方 API 挂掉，页面不白屏、不弹错、不卡音乐/天气 | 断网 + 故障注入测试 |
| 可测试 | 关键逻辑有单测，主流程有 e2e 冒烟 | `pnpm test` 在 CI 通过 |
| 可演进 | 依赖能升、功能能加、后来者（或未来的你）能看懂 | 季度依赖升级不炸，PR 有 lint/test 门禁 |

### 1.2 明确不做（避免过度设计）

- 不一次性全量 TypeScript 重写（新增文件用 TS，存量渐进迁移）；
- 不引入后端/数据库（个人主页不需要）；
- 不做微前端、组件库、Monorepo；
- 不为了"新技术"迁移 Nuxt/Astro——除非 SEO 成为明确需求（见 §7 决策点）。

### 1.3 关键指标

上线后持续观察：

- 构建 < 2 分钟；
- JS gzip ≤ 180 KB（当前 134.6 KB），CSS gzip ≤ 30 KB（当前 23.1 KB）；
- Lighthouse（移动端）：Performance ≥ 90、Accessibility ≥ 90、Best Practices ≥ 95；
- 首屏无未捕获异常，第三方请求失败不产生可见错误；
- 核心工具函数/服务层单测覆盖率 ≥ 70%。

## 3. P0：基线修复

> 目标：改动小、收益最大。完成后项目应达到"换任何域名/任何 API 都能跑起来"的状态。
> 状态：**已完成（2026-11-05）**，实施记录见附录 C。

1. **配置三处错误**（`.env.example`）
   - `VITE_SITE_URL="zowaysat"` 不是域名（没有点），补成真实域名；否则 Logo 后缀为空、页脚链接变成 `//zowaysat`；
   - `VITE_SITE_APPLE_LOGO` 指向 `/images/logo/apple-touch-icon.png`，实际文件在 `/images/icon/apple-touch-icon.png`，构建后 3 个 apple-touch-icon 链接全部 404；
   - 补充音乐关闭说明（`VITE_SONG_ID` 留空即可不渲染播放器）。
2. **构建期 env 校验**：新增 `scripts/check-env.mjs`，校验必填 `VITE_*`；`package.json` 的 `build` / `dev` 在 `vite` 之前先执行校验。彻底消灭"无 `.env` 时 `vite-plugin-pwa:build URIError`"这种隐晦崩溃。
3. **服务降级（P0 最小版）**
   - 壁纸：默认只用本地 10 张；远程源（Bing / vvhan 风景 / vvhan 二次元）放入 feature flag，失败静默回退本地；
   - 音乐：先修错误处理（见第 4 条），再决定保留或默认关闭；
   - 天气：主接口失败 → 备用 → 显示"—"，不弹长时报错。
4. **修 `Player.vue` 异步错误**：`try/catch` 包 `Promise.then` 链捕获不到 reject（`src/components/Player.vue` 的 `onMounted`），改为 `await` + `catch`，失败时置 `store.musicIsOk = false` 并只提示一次。
5. **修 `v-html` 歌词**（`src/components/Footer.vue`）：改为文本插值，或对歌词做白名单转义，消除第三方歌词 XSS 面。
6. **去掉全局劫持**：全局右键禁用（`src/App.vue`）、自定义光标（`src/utils/cursor.js`）改为配置开关，默认关闭；它们是可访问性与长期维护的最大负债。
7. **音乐懒加载**：`Player` 只在用户首次打开播放器时挂载，避免首屏请求歌单。
8. **pnpm 构建脚本白名单**：本次验证时 `esbuild`、`vue-demi` 的构建脚本被拦截（`ERR_PNPM_IGNORED_BUILDS`）。pnpm 12 已不再读取 `package.json` 的 `pnpm` 字段，改为在 `pnpm-workspace.yaml` 中用 `allowBuilds` 放行这两个包。

## 4. P1：目标架构（重构，不重写）

### 4.1 目录结构

```
src/
  config/index.js        # 唯一配置入口：读取+校验 env，导出冻结的 config 对象
  services/              # 外部能力适配层（全部可替换、可 mock）
    http.js              # fetch 封装：超时、AbortController、错误归一化、重试
    weather.js           # 高德 → 备用 → 本地兜底
    music.js             # Meting / 本地 playlist.json / 关闭
    wallpaper.js         # local / remote providers
    hitokoto.js
  composables/
    useSiteUrl.js        # 统一域名解析（当前 4 处重复）
    useNow.js            # 全局唯一 ticker（替换 Func / TimeCapsule 各自的 setInterval）
    useBreakpoint.js     # 替代 JS 读 innerWidth + 手写媒体查询双轨
    usePlayer.js
  stores/                # 拆成 ui / settings / player 三个 store
  components/ views/ styles/ assets/   # 保留现有目录，减少 churn
scripts/check-env.mjs
tests/unit/ tests/e2e/
```

### 4.2 配置层

- 24 处 `import.meta.env.*` 全部改为通过 `config` 访问；
- 补 `src/vite-env.d.ts` 给 `VITE_*` 类型提示；
- 新增 `src/content/site.json`、`src/content/social.json`，把现有 `siteLinks.json` / `socialLinks.json` 迁入，并加 JSON Schema 校验。

### 4.3 服务层契约

```js
// services/weather.js
export async function getWeather({ signal }) → { city, text, temp, wind } // 统一结构
// 内部链路：amap(5s) → fallback(5s) → { text: "—" }；任一环节失败不抛给 UI
```

- 所有请求带超时 / 取消；
- 返回值统一结构，UI 不感知供应商；
- 单测用 `msw` 或 `vi.stubGlobal("fetch")` 覆盖成功 / 超时 / 畸形响应三种情况。

### 4.4 状态层

- `store/index.js` 拆为 `ui`（面板开关）、`settings`（持久化）、`player`（播放器）；
- 持久化 key 改为 `home:state:v1` 并加 `version` 字段，启动时迁移旧 `data` key，避免字段变更导致脏数据。

### 4.5 样式层

- `global.scss` 只保留变量 / mixin，不再通过 `additionalData` 注入每个 SFC 的顶层规则（消除重复 CSS）；
- 颜色 / 圆角 / 模糊抽成 CSS 变量，为主题化做准备；
- 字体子集化：Pacifico 只保留 Logo 用到的字母、UnidreamLED 只保留数字（315 KB 可降到几十 KB）。

> 已落地（2026-11-05）：子集脚本见 `scripts/subset-fonts.mjs`；Pacifico 保留 ASCII（域名可自定义）、
> UnidreamLED 保留数字与符号，合计 43.5 → 14.5 KB；未使用的 315 KB 备用完整字体不再随站点分发。
> 另：已移除第三方 HarmonyOS 字体 CSS，正文改用系统字体栈（消除首屏字体阻塞、CDN 防盗链失效与隐私风险）。

### 4.6 交互与可访问性

- 所有 `div` 操作改为 `button` + `aria-label`，补 `:focus-visible`；
- 全局 `user-select: none` 仅保留在装饰元素；
- 动画加 `@media (prefers-reduced-motion: reduce)` 降级；
- 右键 / 光标等"个人风格"功能用 `VITE_FEATURE_*` 开关控制。

> 已落地（2026-11-05）：简介卡片 / 网站链接 / 一言刷新 / 音乐控制 / 盒子与设置图标等交互元素改为原生
> `button` 并补无障碍名称；新增 `.plain-button` 重置、全局 `:focus-visible` 焦点样式、
> `prefers-reduced-motion` 降级；正文恢复可选中，仅装饰元素禁用选择；Esc 可按层级关闭浮层；
> 设置项 switch 通过 `label` 映射为 `aria-label`；e2e 增加键盘操作与 reduced-motion 用例。

### 4.7 PWA / 缓存

- 预缓存 app shell + 本地资源；`js/css` 依赖 workbox revision 机制，不再用 `CacheFirst` 运行时规则（避免升级后 chunk 不一致）；
- HTML 用 `NetworkFirst`；
- 更新提示保留，但改为一键刷新；
- 离线时页面可用，天气/一言显示占位。

> 已落地（2026-11-05）：预缓存 37 项 / 600 KiB（app shell、图标、子集字体、设置面板分包；壁纸与音乐分包不进预缓存，
> 避免安装 Service Worker 时抢占首屏带宽，壁纸走运行时 image CacheFirst）；
> HTML 导航 NetworkFirst（3s 超时回退）；图片 CacheFirst + 30 天过期；`cleanupOutdatedCaches` 清理旧缓存；
> 更新提示仅在有旧 controller 时触发，点击立即刷新。e2e 新增“断网仍可打开首页”。

## 7. 风险与决策点

### 7.1 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 上游存档、第三方 API 陆续下线 | 音乐 / 远程壁纸 / 备用天气随时再挂 | P0 起就"本地优先 + 开关 + 降级"，不依赖单一供应商 |
| Vue/Vite/EP 大版本升级 | 隐性回归 | 先测试后升级；每个大版本独立 PR + tag |
| PWA 缓存 | 发版后用户看到旧页面 / chunk 错 | 预缓存 + revision，HTML NetworkFirst，保留更新提示 |
| 全局交互副作用 | 可访问性差、难维护 | 改为开关，默认关闭 |
| 个人主页过度工程化 | 维护成本反超收益 | 严格按阶段推进；P3 全部"按需" |

### 7.2 需要尽早拍板的三个决策

1. **SEO 是否重要？** 重要 → 增加预渲染（`vite-plugin-prerender` 或迁 Astro）；不重要 → 保持 SPA，只补 OG/meta。
2. **是否引入 TypeScript？** 建议"新文件 TS + `allowJs`"渐进，不重写存量 `.vue` 的 `<script setup>`（可后续逐文件迁）。
3. **音乐播放器去留？** 没有稳定音源就默认关闭（`VITE_SONG_ID` 为空），保留组件；有自建 Meting 再开。
